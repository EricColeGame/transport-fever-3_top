## 都市交通ネットワークにおけるトラムの戦略的役割

シミュレーション内のすべての発展都市は、自家用車の普及に伴って深刻な成長痛に直面します。都市の黎明期であれば、手頃なバス路線でも住宅街と商業地区の間で住民を十分に運ぶことができます。しかし、建物のレベルが上がり過密化が進むと、バスは自家用車の渋滞に巻き込まれ、運行頻度も乗客の満足度も急落してしまいます。

そこで不可欠となるのが、トラム専用インフラの導入です。路面電車やライトレール（LRT）は、短距離を走る市バスと大量輸送を担う都市間旅客列車の間にある輸送ギャップを埋める存在です。道路に直接埋設された軌道や、分離された中央分離帯上を走行することで、1本のトラム路線は道路の混雑を悪化させることなく、バス路線の3〜4倍の旅客量を輸送できます。

```
[住宅エリア] ---> (ローカルトラム・フィーダー) ---> [中央駅] ---> (都市間幹線鉄道)
                                                          |
                                                          v
                                                    [商業・工業エリア]
```

プレイヤーの経験談やコミュニティの検証結果からも明らかなように、乗客の幸福度は待ち時間の短さや移動速度と直結しています。停留所で待たされる時間が長すぎると、市民は自家用車を選び始め、主要幹線道路に連鎖的な大渋滞を引き起こします。綿密に計画された**Transport Fever 3 トラム**を導入すれば、都市内の交通を円滑に維持する確固たる幹線が生まれ、最も収益性の高い都市間特急列車へ継続的に乗客を送り込めるようになります。

| 指標 | 市内バス | 近代的な路面トラム | 重量旅客鉄道 |
| :--- | :--- | :--- | :--- |
| **初期投資額** | 低 | 中程度 | 非常に高い |
| **必要なインフラ** | 基本的な舗装道路 | 軌道および架線設備 | 専用の重軌条と信号設備 |
| **輸送定員** | 低（10〜35人） | 中〜高（40〜120人） | 非常に高い（150〜400人以上） |
| **渋滞の影響度** | 高（渋滞に巻き込まれる） | 低〜中（専用レーン活用時） | ゼロ（独立した専用軌道） |
| **座席あたりの運行コスト** | 中程度 | 低 | 非常に低い（満員運行時） |
| **理想的な役割** | 郊外のフィーダー循環線 | 稠密な都市回廊・基幹路線 | 都市間輸送・高密度拠点連絡 |

## トラムの軌道インフラと道路管理

路面電車を走らせる前に、まず道路網を整備する必要があります。標識ポールやバスターミナルを設けるだけで済むバスとは異なり、路面電車には専用のレールと架空電車線（架線）が必須です。線路を敷く前に道路の階層構造を意識しておかないと、のちのち深刻な物流・交通トラブルに悩まされることになります。

高効率なネットワークを構築するために、開発元は将来の交通アップグレードを見据えた道路設計を推奨しています。[Urban Games公式ウェブサイト](https://www.urbangames.com/)で議論されている交通戦略でも、ゲーム序盤から複合的な交通手段を組み込んでおくことで、後々の破壊的な都市解体を回避できると指摘されています。

### 道路のアップグレードと架線電化

既存の道路をアップグレードすることは、大通りを通すために歴史ある街並みを破壊するよりもはるかに安上がりです。都心の回廊を近代化する場合は、道路アップグレードツールを選択し、トラム軌道を有効にして目的のルート上をドラッグします。時代が電動トラムの年代に達している場合は、必ず架線電化も有効にしてください。電化されていないと、電気車両は車庫から出庫できません。

| 道路タイプ | トラム軌道の敷設 | 専用レーン対応 | 最適な用途 |
| :--- | :--- | :--- | :--- |
| **小型市街地道路** | 可（併用軌道） | 不可（一般車と車線を共用） | 歴史地区、低密度の郊外 |
| **中型4車線道路** | 可（併用または外側車線） | 可（外側車線の進入規制） | 複合商業エリア |
| **大型6車線アベニュー** | 可（中央分離帯または外側） | 可（中央分離帯の専用通行帯） | 都市を縦断・横断する主要大動脈 |
| **郊外道路／高速道路** | 制限あり | 不可 | 衛星都市・周辺集落との接続 |

### 専用レーンによる道路渋滞の回避

初心者が陥りがちな最大のミスは、交通量の多い一般車車線をトラムと共用させてしまうことです。一般乗用車が右左折のために停止したり信号待ちでつかえたりすると、後続のトラムも巻き添えを食らって立ち往生してしまいます。

これを防ぐには、中型以上の道路をアップグレードしてバス・トラム専用レーンを必ず設定しましょう。これにより自家用車は内側車線に追いやられ、歩道寄りまたは中央分離帯寄りの車線が公共交通専用として確保されます。**Transport Fever 3 トラム**に専用通行帯を設ければ、一般車線がどれほど渋滞していようとも、トラムは一定の速度を維持して定時運行を続けられます。

```
6車線アベニューの断面図：
[歩道] | [トラム／バス専用レーン] | [一般車線] | [一般車線] | [一般車線] | [一般車線] | [トラム／バス専用レーン] | [歩道]
```

## 車両の変遷：各時代への対応

シミュレーションのタイムラインが進むにつれて、利用可能な車両は劇的に進化します。艦隊を適切に管理するためには、より高速で輸送能力の高い新モデルが登場した段階で、タイムリーに車両の更新を行う必要があります。

### 初期時代：馬車鉄道と蒸気トラム

初期の時代は乗客数も少なく、都市の境界もコンパクトです。初期の馬車鉄道や原始的な蒸気トラムは、輸送力も小さく最高速度も控えめです。しかし、徒歩に頼りがちだった市民に公共交通を利用する習慣を根付かせる重要な役割を果たします。

この段階では、住宅地の外縁部と都心部を結ぶコンパクトな循環ルートに注力しましょう。低速車両でも許容範囲内の運行頻度を保てるよう、路線長は短めに抑えるのがコツです。

### 産業時代：電気路面電車

架線の登場により、加速性能と最高速度が飛躍的に向上します。20世紀中盤の電気路面電車を活用すれば、所要時間を大幅に悪化させることなく、拡大する工業エリアへ路線を延伸できます。

この時代は、古い車両を最新の電気モデルへと置き換えることで、維持費を大幅に圧縮できます。車両を発注する前に、分岐器や車庫への連絡線を含め、路線網のすべての区間に確実に架線が張られているかを必ず確認してください。

### 現代：連接型ライトレール（LRV）

現代に入ると、複数の都市エリアが融合して広大な巨大都市へと発展します。現代的な連接式路面電車や低床型ライトレール車両（LRV）は、1編成あたり100人を超える定員、迅速な乗降速度、一般車両に匹敵する最高速度を誇ります。

専用レーンを備えた大通りで最新の**Transport Fever 3 トラム**を走らせれば、地下鉄建設に比べてわずかな初期投資コストで、地下鉄並みの輸送力を発揮させることが可能です。

| 車両の時代 | 動力方式 | 平均速度 | 定員範囲 | 維持管理負担 |
| :--- | :--- | :--- | :--- | :--- |
| **初期（1850–1900）** | 馬力／蒸気 | 15–25 km/h | 10–25人 | 初期投資は低廉、老朽化ペナルティ大 |
| **中期（1900–1960）** | 初期電動 | 30–50 km/h | 30–65人 | 中程度、安定した運用コスト |
| **後期（1960–2000）** | 近代電動 | 50–65 km/h | 60–90人 | 高効率、保有台数規模に依存 |
| **現代（2000以降）** | 連接型LRV | 60–80 km/h | 90–140人以上 | 初期投資は高いが、一人あたり費用は最小 |

## 路線レイアウト戦略：循環型 vs スパイン（基幹）型

交通路線のルーティング方針は、ネットワークが巨額の利益を生み出すか、それとも赤字を垂れ流すかを決定づけます。初心者は街路をくまなく巡る巨大な環状ルートを作りたがりがちですが、熟練したプランナーは構造化された「トランク＆フィーダー（幹支線網）」設計を好みます。

```
トランク＆フィーダーパターン：
(郊外バス循環線 A) \
                      ---> [乗換ハブ駅] === [トラム基幹軸] === [商業センター]
(郊外バス循環線 B) /
```

### 直線スパイン（基幹軸）設計

高密度な都市回廊で最も効果的な構成は、複線の直線スパイン設計です。このレイアウトでは、都市のメインストリートを線路が真っ直ぐ貫き、街の両端にある転回ループ線または両渡り線（シーサスクロッシング）で折り返します。

直線ルートには運用上の大きなメリットがあります：
- まっすぐな経路設計により乗客の遠回りをなくし、移動時間を大幅に短縮。
- 運行間隔（ヘッドウェイ）が予測しやすく、車両の間隔調整やラインバランシングが容易。
- 都市境界に新たな住宅地区が開発されても、先端を延伸するだけで対応可能。

### 放射状フィーダーパターン

複数の工業団地や点在する住宅地を抱える大規模マップでは、放射状のフィーダーデザインが威力を発揮します。それぞれの地区を起点とする複数のトラム路線が、中央駅や中心業務地区（CBD）に向けて集束する構造です。

交通を円滑に保つため、折り返しの車両が不要に対向車線を横切らないような線形を工夫してください。路線の終端部にはラウンドアバウトや一方通行のループを設けることで、混雑した交差点を詰まらせることなくスムーズに折り返し運行を行えます。

| 路線戦略 | 旅客スループット | 渋滞耐性 | 建設の難易度 | 拡張性 |
| :--- | :--- | :--- | :--- | :--- |
| **直線スパイン型** | 高 | 極めて高い | 低 | 容易（両端を延伸） |
| **放射状ハブ＆スポーク型** | 非常に高い | 中〜高 | 中程度 | 高い（新支線を追加） |
| **一方通行ループ型** | 低〜中 | 低（渋滞に極めて脆弱） | 低 | 低い（停車の追加で全体が遅延） |
| **都市間連絡トラム** | 中程度 | 高 | 中〜高 | 中程度（距離による制限あり） |

## ボトルネックの解消とダンゴ運転の防止

どれほど緻密に設計されたトラムネットワークであっても、運行頻度が崩れるとトラブルに見舞われます。最も厄介な問題の一つが、3〜4台のトラムが同じ駅に同時に到着し、その後10分間も車両が来なくなる「ダンゴ運転（バンチング）」です。

### 運行間隔と待ち時間の適正管理

車両がダンゴ状態になると、先頭の車両が待っている乗客をすべて拾う一方で、後続の車両は完全にガラ空きのまま走ることになります。これは路線の収益性を破壊し、後続区間での乗客待ち時間を跳ね上げる原因になります。

混雑する**Transport Fever 3 トラム**路線でのダンゴ運転を解消するには：
1. 路線管理ウィンドウを開き、「車両間隔調整（Line Spacing）」機能を有効にして、運行間隔を自動で均等化させます。
2. 最も混雑する終点駅の「最低待ち時間」設定を調整し、後続車両がダイヤに追いつく猶予を確保します。
3. 停留所の間隔を均等に保ちます。50メートルごとに停留所を配置すると、巡航速度で走る時間よりも加減速と乗降に費やす時間が長くなってしまいます。
4. 車庫は混雑した中心街の交差点脇ではなく、側道や引き込み線ループ上に配置します。

### 駅の配置とプラットフォームの最適化

停留所を置く場所は、車両の走行パフォーマンスに直結します。交通量の多い十字路の手前すぐの位置にトラム停留所を置くと、乗降が完了した直後に赤信号で止められ、停車時間が実質2倍になってしまいます。

トラムの乗り場は、可能な限り交差点を通過した「直後」に配置してください。これにより、トラムは交差点を抜けてから乗客の乗降を行えるため、乗降待ちの間に交差道路の交通を塞いでしまうリスクを最小限に抑えられます。

| 運用上の問題 | 主な原因 | 即座に取れる対策 | 根本的な長期的解決策 |
| :--- | :--- | :--- | :--- |
| **車両のダンゴ運転** | 乗降時間のバラつき | 後続車を車庫に戻すか反転させる | 自動車両間隔調整の適用と停留所間隔の均一化 |
| **トラムが渋滞に巻き込まれる** | 狭い道路での一般車混入 | 4車線以上の専用レーン付き道路へ改修 | バイパス環状線を整備して一般車を迂回させる |
| **乗客の長蛇の列** | 輸送力不足または運行頻度の低さ | 路線への投入車両を増車する | 大容量の現代型連接LRVへ置き換える |
| **路線開設時の車庫前渋滞** | 全車両の一斉出庫 | 車両購入を15〜30秒ずつずらして実行 | 複数の車庫出入庫線へ分散配備する |

## 実践ステップ：高輸送力トラム回廊の構築手順

初日から正しい手順でトラム回廊を整備しておくことで、後から多額の費用をかけて軌道を敷き直す事態を防げます。新しい路面電車インフラを導入する際は、実証済みの以下の手順に従ってください：

1. **旅客需要の調査**：都市の移動先オーバーレイを確認し、市民が住居、商業施設、工場の間でどのような経路を移動しているかを特定します。
2. **主要動脈のアップグレード**：これらの地区を結ぶ目抜き通りを選択し、バス・トラム専用レーンを有効化した4車線または6車線道路へとアップグレードします。
3. **電化軌道の敷設**：車庫へのアクセス線を含め、ルート全体でトラム軌道および架線電化オプションが有効になっていることを確認します。
4. **停留所の設置**：停留所間隔は200〜400メートルを目安とし、交差点の手前ではなく通過直後の位置を優先して設置します。
5. **終端ループの建設**：路線の両端にすっきりとした転回ループや渡り線を敷設し、一般車の流れを妨げずにトラムが方向転換できるようにします。
6. **車両の配備と間隔調整**：現在の需要に見合った車両を購入し、路線設定で自動車両間隔調整を有効化します。

この配備プロセスを標準化することで、**Transport Fever 3 トラム**は安定した運行利益を叩き出しながら、都市全体の人口増加を劇的に加速させてくれるはずです。

## Transport Fever 3 トラムに関するよくある質問（FAQ）

### 都市の発展に合わせてTransport Fever 3のトラムをアンロック・更新するにはどうすればよいですか？
トラムの車両やインフラは、ゲーム内の時代が進行するにつれて順次アンロックされます。電気トラムを運行するには、道路アップグレードツールを使用して、道路に「トラム軌道」と「架線」の両方を敷設する必要があります。新しいトラムモデルが登場したら、路線メニュー内の自動車両交換マネージャーを活用することで、旅客輸送サービスを止めることなく車両を一括更新できます。

### 都市内交通において、トラムはバスより優れていますか？
はい、高密度の回廊においては、路面電車はバスよりもはるかに優れています。バスは初期投資額が抑えられるものの、路面電車は1編成あたりの定員が大幅に多く、中央または歩道寄りの専用レーンを走行することで高い運行効率を誇ります。交通量の多い基幹路線に**Transport Fever 3 トラム**を導入すれば、車両の過密化を防ぎ、都市が初期段階を超えて成長した際に格段に高い利益率を達成できます。

### なぜトラムが車庫から出てこないのでしょうか？
車両が出庫できない原因として最も多いのは、架線の張り忘れや軌道の接続不良です。電気路面電車を購入した場合は、車庫から指定された運行ルートまでのすべての道路セグメントに架線が完全に通っているか点検してください。分岐器の線路抜けや、電化されていない橋梁セグメントが1箇所でもあると、電気トラムは指定路線へ到達できなくなります。

### 一般車がトラムの線路を塞ぐのを防ぐにはどうすればよいですか？
一般車をトラムの軌道から排除するには、路線が通る道路を「バス・トラム専用レーン」付きの複数車線道路にアップグレードしてください。さらに、ダウンタウン地区を迂回するバイパス環状道路を建設して都市全体の交通流を誘導すれば、自家用車の通勤者を都心からバイパスへ逃がし、中心部の回廊を公共交通のためにクリーンに保つことができます。
