## キャンペーンの基本構造と時代の進行

包括的な輸送シミュレーションキャンペーンの際立った特徴は、年代順に沿った進行にあります。キャンペーンの構成は通常、いくつかの時代ごとの幕（アクト）に分かれており、それぞれの時代特有の技術的限界と経済的圧力への対処が求められます。

```
時代1：開拓者（1850～1900年） ──► 蒸気動力、馬車、基本的なばら積み貨物
時代2：産業家（1900～1950年） ──► 初期の燃焼機関、重量貨物鉄道、路面電車の拡張
時代3：近代化（1950年～現在）  ──► 電気牽引、航空貨物ハブ、高速鉄道
```

### 時代1：フロンティアと開拓者の物流（1850–1900年）
キャンペーンの初期段階では、素朴な機械を使って厳しい自然の地形を克服することに重点が置かれます。機関車の出力は低く、急勾配は重量貨物の運行を妨げ、道路輸送は鈍足な馬車に限られます。この時代に成功するためには、線路の勾配を最小限に抑え、車両の運動量を維持するために自然の等高線に沿ったルートを建設する必要があります。

### 時代2：産業の拡大と都市化（1900–1950年）
中盤戦では、緻密な製造業ネットワークへと焦点が移ります。製鉄所、化学工場、石油精製所は、原材料の絶え間ない流入を必要とします。同時に、拡大する都市は専用の通勤ネットワークを必要とするため、プレイヤーはボトルネックを発生させたり渋滞を引き起こしたりすることなく、旅客と貨物の混交回廊を管理しなければなりません。

### 时代3：現代の交通時代（1950年～現在、そして未来へ）
終盤のチャプターでは、実際に稼働している運行ネットワーク上でインフラをアップグレードする能力が試されます。老朽化した蒸気機関車デポを電化回廊へと置き換え、大容量の航空貨物を導入し、過密に発展した都市部を縫うように高速旅客線を走らせる必要があり、これらすべてを運行予算の破綻なしに成し遂げなければなりません。

| 歴史的時代 | 主要車両技術 | コアリソースチェーン | 一般的な運用の制約 | 戦略的優先事項 |
| :--- | :--- | :--- | :--- | :--- |
| **開拓者（1850–1900）** | 蒸気機関車、馬車 | 木材、石材、穀物 | エンジン牽引力の不足、急勾配によるペナルティ | 山を迂回するルート選定、高価なトンネル建設の回避 |
| **産業（1900–1950）** | 大型蒸気機関車、初期ディーゼル、路面電車 | 原油、燃料、鋼鉄、機械・工具 | 都市部の道路渋滞、混交交通による遅延 | 貨物線と都市通勤路線の分離 |

## キャンペーンミッションでマスターすべき重要メカニクス

スクリプト化されたミッションで勝利を収めるには、気軽なサンドボックスプレイ以上のシステム理解が必要です。サンドボックスモードであれば、ある産業ルートが一時的に赤字を出しても、補助金や潤沢な予備資金で乗り切ることができます。しかし、**Transport Fever 3のキャンペーン**では、厳格なミッション制限時間、予算上限、多段階の物流チェーンにより、大雑把なネットワーク設計は即座にペナルティへと繋がります。

### 1. 運行頻度と輸送容量のバランス
経験の浅い配車担当者が陥りがちな罠は、生産側の需要が追いついていないにもかかわらず、巨大で高価な列車を路線に過剰配備してしまうことです。キャンペーンシナリオでは以下の点が重要になります。
- **運行頻度が需要と産業の利用を促進する：** 定期的な集荷を行うことで、駅ホームの滞留を防ぎ、工場の在庫過多を抑制できます。
- **維持費がキャッシュフローを圧迫する：** 半分空の編成を走らせ続けると、営業利益率は急速に悪化します。
- **編成の長さとプラットフォームの長さを一致させる：** プラットフォームをはみ出す列車は分岐器を塞ぎ、本線全体で壊滅的なデッドロックを引き起こします。

### 2. 複数中継サプライチェーンと供給圏
産業ミッションでは、多層的な流通ネットワークが頻繁に要求されます。例えば、鉄鉱石と石炭から鋼鉄を製造し、その鋼鉄を機械工場へ輸送し、完成した製品を都市の市場へ配送するケースです。

```
[鉄鉱石鉱山] ──(ばら積み列車)──┐
                               ├──► [製鉄所] ──(無蓋車・平板車)──► [機械・工具工場] ──► [都市の商業地区]
[石炭鉱山]   ──(ばら積み列車)──┘
```

このチェーンのどこか1つのリンクで供給不足や輸送のボトルネックが発生すると、上流の供給元も生産を減速させ、物流ネットワーク全体に連鎖的な財政破綻を引き起こします。

| 運用の問題 | キャンペーンでの兆候 | 主な原因 | 推奨される解決策 |
| :--- | :--- | :--- | :--- |
| **プラットフォームの混雑** | 赤い警告アイコン、貨物の劣化・消失 | 車両の運行頻度不足 | 路線に車両を追加、貨物プラットフォームモジュールの拡張 |
| **分岐器のデッドロック** | 列車同士の正面衝突・停止 | 分岐手前の不適切な信号配置 | 一方通行パス信号の使用、閉塞長を列車長に合わせる |
| **工場の生産停止** | 「消費者がいません」のステータス表示 | 下流目的地への配送失敗 | 最終市場へのトラック配送ルートと供給圏半径を確認 |
| **突然の資金枯渇** | 急速なマイナス残高アラート | 損益分岐点を下回る積載率での運行 | 列車長の縮小または汎用貨車の配備 |

## ボーナス目標の達成とメダルの完全制覇

シリーズのベテランなら誰しも、基本的なミッション条件を達成するだけでは戦いの半分に過ぎないことを知っています。**Transport Fever 3のキャンペーン**を真に極める醍醐味は、ミッションごとに設定されたあらゆるオプショナルメダルとボーナス目標を獲得することにあります。

オプショナルタスクは、一般的に次の3つのスタイルに分類されます。
1. **スピードランの課題：** 厳格な期日までに規定トンの物資を届ける、あるいは目標人数の乗客を輸送する。
2. **歴史的制約：** 歴史的に正確な車両クラスのみを使用する、特定の技術の使用を避ける、または指定されたランドマークを破壊せずに保持する。
3. **物流パズル：** 銀行からの融資を受けずに経済危機を解決する、あるいは100%の満載効率評価で路線を運用する。

| メダルの区分 | 典型的なチャレンジ目標 | よくあるプレイヤーのミス | プロの戦略 |
| :--- | :--- | :--- | :--- |
| **効率メダル** | 平均積載率85%以上を維持 | 最初から最大の連結長で購入する | 小規模から開始し、駅の備蓄増加に合わせて徐々に貨車を追加 |
| **節約メダル** | 追加の借入なしでシナリオを完了 | 序盤に複線本線を過剰建設する | 収益が安定するまで単線と行き違い待避線（交換設備）を活用 |
| **保護メダル** | 市街地や史跡の破壊を回避 | 自動解体を使って直線的な線路を引く | 史跡周辺を迂回して線路を曲げる、許可されていれば橋梁を活用 |
| **スピードマイルストーン** | 厳しい時間制限内に緊急物資を配送 | 貨物列車を低速な旅客列車の後ろで待機させる | 目標配送用の専用急行バイパス線を敷設 |

物流シミュレーションをやり込んだプレイヤーのコミュニティ報告によると、難易度の高いボーナスタスクを最も確実にクリアする方法は、初期配置を計画する間、ゲームを標準速度で進行させることです。3倍速で急いで進めてしまうと、銀行残高が赤字に転落するまで致命的な資材不足に気づけないことがよくあります。

## 高収益な輸送ネットワークの構築手順：ステップ・バイ・ステップ

新しいキャンペーンシナリオを開始する際、体系的なワークフローに従うことで、序盤の財政破綻を防ぐことができます。持続可能な利益を確立するために、以下の運用ロードマップを活用してください。

```
[1. 資源調査] ──► [2. 単線幹線の敷設] ──► [3. 都市フィーダーループの構築] ──► [4. 利益の再投資]
```

1. **徹底的な資源調査の実施：** ロードが完了したらすぐにゲームを一時停止します。原材料の採掘地、中間精製所、受入先の都市部をマッピングします。最初の資金源（ドル箱路線）を確立するために、短距離で平坦な接続ルートを見極めてください。
2. **費用対効果の高い鉄道幹線の配置：** 高価な複線を敷くのではなく、中央に行き違い待避線を設けた単線を敷設します。複数の編成が安全に回廊を共有できるよう、等間隔に閉塞信号機を設置します。
3. **都市内フィーダーシステムの統合：** 都市間旅客駅は、そこへ乗客を運ぶローカル交通網が整って初めて機能します。住宅地区と商業地区を通るバスや路面電車の環状ルートを敷き、旅客を直接鉄道駅へ集約します。
4. **段階的なネットワークの拡張：** 最初の回廊が安定したプラスのキャッシュフローを生み出すようになったら、外側へ展開します。得られた配当を立体交差化、複線化、高性能な新車両の導入へと再投資していきましょう。

## キャンペーンモード vs. フリープレイサンドボックス：あなたに合うのはどちら？

**Transport Fever 3のキャンペーン**は整理された目標と魅力的なストーリーを提供しますが、多くのプレイヤーは手続き型のサンドボックスモードにも何百時間もの情熱を注いでいます。これら2つのプレイスタイルの違いを理解することで、自分の時間をどこに投資すべきかが見えてきます。

| モードの属性 | キャンペーンモード | サンドボックス / フリープレイモード |
| :--- | :--- | :--- |
| **目標スタイル** | スクリプト化された歴史的目標、マイルストーン、ボーナスメダル | 自由形式でプレイヤーが決める帝国建設 |
| **資金難易度** | 厳格な予算、融資の制限、目標未達ペナルティ | 難易度調整可能、無制限の資金オプションあり |
| **マップの地形** | 独自の課題を持つ作り込まれた地域マップ | カスタムバイオームスライダー付きの手続き型生成シード |
| **車両のアンロック** | 時代制限およびミッションごとに厳選されたラインナップ | 時間経過によるアンロック、または全車両解放サンドボックス |
| **学習価値** | 複雑なメカニクスの技法やパズル解決能力を習得 | 制限のない大規模メガハブの設計を促進 |

定められた勝利条件のもとで物流パズルを解き明かすのが好きな方にとって、キャンペーンは極めて充実した達成感のある体験を提供します。何の制限もない理想的なメガマップの上に何千キロもの線路を敷き詰めたい場合は、キャンペーンで腕を磨いた後にサンドボックスの世界へ飛び込むと良いでしょう。

## よくある質問（FAQ）

### Transport Fever 3のキャンペーンは過去作と何が違いますか？
**Transport Fever 3のキャンペーン**は、より複雑な多段階サプライチェーン、強化された都市発展システム、プレイヤーの効率に応じて変化する動的なシナリオ課題を導入することで、前作からさらなる進化を遂げています。作り込まれたマップはリアルな歴史的背景を提供し、多様な地理的制約の下で路線構築力と資金管理能力が試されます。

### キャンペーンの初期ミッションで貨物線が赤字になるのを防ぐにはどうすればよいですか？
貨物線の赤字は通常、復路の空荷走行や、編成が長すぎることによる運行コストの過大さが原因です。黒字を維持するためには、列車の長さを工場の生産量に合わせ、駅の需要が高まる前に無駄な貨車を買い足さないようにし、適切な一部積載や満載待機の設定を活用してください。

### 1回のプレイですべてのキャンペーンメダルを獲得できますか？
ほとんどのミッションメダルは1回のプレイで獲得可能ですが、期限内のスピード達成と低負債の維持など、一部の目標には背反する条件が含まれる場合があります。まずはマップを把握するためにシナリオを1回クリアし、その後重要なチェックポイントからロードし直すか、最適化された計画で再スタートすることが、メダル100%達成への最も確実なアプローチです。

### 初期時代のキャンペーンシナリオで旅客路線は利益を出せますか？
利益を出すことは可能ですが、適切な都市内交通との連携が不可欠です。通勤客が駅まで移動できない場合、2つの小さな町の間を結ぶ旅客列車は苦戦を強いられます。住宅街と旅客ターミナルを結ぶバスや馬車のフィーダーループを必ず併設し、運賃収入を最大化できるようにしてください。
