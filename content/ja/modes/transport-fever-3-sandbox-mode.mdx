## Transport Fever 3 サンドボックスモードの主な特徴

サンドボックス体験は、プレイヤーの主体性を核に構築されています。歴史的な時代に沿って車両を順番にアンロックしたり、ローンの利息を心配したりする代わりに、世界中の車両群、柔軟な建設メニュー、カスタムシミュレーションの調整レバーに即座にアクセスできます。

長年のシミュレーションファンは、[Urban Games](https://www.urbangames.com/) の公式開発者ポータルで歴代の基礎的作品を振り返り、交通メカニクスが世代を経てどのように進化してきたかを確認することがよくあります。今作において、クリエイティブなプレイの自由度は前例のない高みに達しています。

以下の表は、通常のキャリアモードや標準のフリープレイシナリオと比較した、サンドボックスプレイで利用可能な基本機能の内訳です。

| 機能カテゴリ | 標準フリープレイモード | Transport Fever 3 サンドボックスモード | プレイヤー側の利点 |
| :--- | :--- | :--- | :--- |
| **資金とキャッシュフロー** | 有限の予算、銀行ローンが必要 | 無限の資金 / 残高の切り替え可能 | 破産の恐怖なしに複雑な線路レイアウトを建設可能 |
| **車両のアンロック** | タイムラインと年代に固定 | 年代ロックの切り替え可能、全車両が利用可能 | クラシックな蒸気機関車と最新の高速電車を混用可能 |
| **都市と産業の配置** | 静的、自動生成 | 完全に自由配置・編集可能 | カスタマイズされたサプライチェーンと独自の都市圏を設計可能 |
| **地形の造成** | 高額な地形編集コスト | 無料または低コストのランドスケープツール | ドラマチックな峠道、深いフィヨルド、運河を造形可能 |
| **都市の成長管理** | 貨物需要によって完全に決定 | 人口と供給上限の手動スライダー | 風情ある村落から爆発的に発展するメガロポリスまで思いのままに演出可能 |

これらの柔軟なメカニクスにより、あなたの交通網は進化し続けるデジタルジオラマとなります。路線の収益を常にチェックし続ける代わりに、景観豊かな山岳鉄道のカント角を完璧に調整したり、重層的な旅客ターミナルをコーディネートしたりすることに何時間も没頭できます。

## 必須のサンドボックス設定と構成オプション

バラストを最初の1キロメートル敷設する前に、開始パラメータを調整して世界がお手元のクリエイティブなビジョンと一致するように整えましょう。**Transport Fever 3 サンドボックスモード**を起動する際、シミュレーションが内部でどのように動作するかを左右する詳細なトグルを調整できます。

プレイヤーの体験やコミュニティの報告によると、車両の利用可能日やメンテナンスの経年劣化を調整するだけで、プレイセッションの雰囲気が劇的に変化することが一貫して強調されています。

| 設定 / トグル | デフォルト設定 | クリエイティブ向け推奨 | ゲームプレイへの影響 |
| :--- | :--- | :--- | :--- |
| **財務上の制約** | 有効なバランスシート | 無効（資金無制限） | 財政的プレッシャーや車両基地の購入コストを完全に排除 |
| **車両の劣化とメンテナンス** | 徐々に見た目が劣化 | 無効または外観のみ | 何十年経っても展示用の車両をピカピカの状態に維持 |
| **日付の進行** | 標準のカレンダー進行 | 一時停止または4倍遅く | 好みの特定の時代で大規模なインフラをじっくり設計可能 |
| **産業の生産上限** | 標準上限（400〜1600） | 上限なし / カスタム倍率 | 大規模な貨物ヤードに向けて膨大な貨物量を創出 |
| **市民の通勤許容範囲** | 標準の経路探索範囲 | 拡張された移動許容範囲 | バス、路面電車、鉄道間の複雑な乗り換えを促進 |

セットアップ画面でこれらのパラメータを時間をかけて調整しておくことで、予期せぬ車両の陳腐化や、細部まで作り込んだ鉄道回廊を意図しない都市のスプロール現象が上書きしてしまうといった、後々の厄介な問題を回避できます。

## ステップ・バイ・ステップ：サンドボックスモードでリアルな鉄道網を設計する

本格的な鉄道網を構築するには、綿密な計画が必要です。抑制となる金銭的ペナルティがないため、非現実的な急勾配や無秩序なスパゲッティジャンクションを作ってしまいがちです。現実世界の工学に基づいた外観と感触を持つレイアウトを構築するには、体系的な設計プロセスに従いましょう。

```
フェーズ 1: 地域測量  -->  フェーズ 2: 幹線回廊  -->  フェーズ 3: 駅の配置  -->  フェーズ 4: 分岐器・交差の設計  -->  フェーズ 5: ディテールと小物の配置
```

以下は、ネットワーク開発のライフサイクルを構造化するための実践的な内訳です。

| ステージ | 主な目的 | 使用する主要ツール | プロのアドバイス |
| :--- | :--- | :--- | :--- |
| **1. 地域測量** | 自然の回廊、谷、河床を特定 | 等高線表示、地形ブラシ | 地理を活かすこと。あらゆる障害物にトンネルを掘るのは避けましょう |
| **2. 幹線軸の確立** | 大容量の複線・複々線旅客路線を敷設 | 並行線路ツール、曲線スムーサー | リアルな列車の加速を実現するため、最急勾配は2.5%以下に維持 |
| **3. ターミナルの選定** | 行き止まり式ターミナルまたは通過駅を配置 | モジュール式駅エディタ | 将来の拡張路線の余地として4〜6本の空きプラットフォームスロットを確保 |
| **4. ヤードと支線の敷設** | 操車場と二次的な支線リンクを構築 | スリップスイッチ、渡り線ツール | 貨物ハブの近くに待避線を設け、待機中の編成を留置 |
| **5. 景観の装飾** | 柵、架線柱、地面テクスチャを統合 | アセットブラシ、造景ツール | 分岐器の周囲にバラストと砂利のテクスチャを重ねて使用感をシミュレート |

**Transport Fever 3 サンドボックスモード**を使用して複雑な線路配置をテストすることで、その路線に多数のアクティブな列車を投入する前に信号のボトルネックを発見できます。

## 都市の成長とカスタム貨物エコシステムの管理

クリエイティブモードの最も強力な側面の一つは、町、工場、資源ノードを手動で配置できることです。標準モードでは、都市は同心円状に自然成長するため、前もって計画していた線路用地が破壊されてしまうことがよくあります。

**Transport Fever 3 サンドボックスモード**では、都市ゾーンを固定したり、住宅街、商業地区、工業地区を手動で塗り分けたりして、秩序を保つことができます。

### 貨物エコシステム設定の比較

リアルなサプライチェーンを求める場合でも、高密度の処理能力テストを行いたい場合でも、サンドボックスツールならカスタム構成が可能です。

| ネットワーク類型 | 貨物の複雑度 | 都市成長への影響 | 最適な用途 |
| :--- | :--- | :--- | :--- |
| **ポイント・ツー・ポイント型産業** | 単一の資源から単一の消費者へ | 最小限（ターゲット供給） | 明快で予測可能なダイヤグラムのテスト |
| **集中型貨物ハブ** | 中央ヤードを経由した多層処理 | 中程度 | リアルなハンプ操車場・仕訳作業の運用 |
| **統合型地域グリッド** | 原料から完成品までの完全な配送 | 高い（急速な人口増加） | 重量貨物回廊やジャンクションのストレステスト |
| **孤立した景観重視のローカル線** | 最小限の農業または観光客輸送 | 極めて低い | 審美的なジオラマやヴィンテージ旅客列車の運行 |

サンドボックスのスライダーで都市の成長率をコントロールすることで、趣のある田舎の停留所がコンクリートジャングルへと膨張するのを防ぎ、ランドスケープの景観的調和を維持できます。

## パフォーマンス最適化と大規模マップのベストプラクティス

サンドボックスモードは広大な建設を後押ししますが、数千もの独立したエージェントが存在する巨大なネットワークはハードウェアの限界を試すことになります。コミュニティの報告によると、上限のない人口と過度に高密度な経路探索ネットワークが、ゲーム終盤のフレームレート低下の主な原因となっています。

ラージやメガロマニアック（超特大）サイズのマップ全体で滑らかなパフォーマンスを維持するには、以下の戦略を活用してください。

| パフォーマンス要因 | リスク要因 | 推奨されるサンドボックス対策 |
| :--- | :--- | :--- |
| **エージェントの経路探索** | 大規模に相互接続された道路網 | 鉄道でのみ接続された、孤立した衛星都市群を構築する |
| **駅の混雑** | 1つのプラットフォームで数千人の乗客が待機 | 編成を長くするか運行頻度を高め、ホーム上の人数を低く抑える |
| **路線の信号チェック** | 高速路線での極端に狭い信号間隔 | 閉塞信号の間隔を列車長の1.5〜2倍程度空ける |
| **アセット密度** | 何百万本も手動配置された木や装飾プロップ | 線路の切り通し付近に詳細な植生を集中させ、遠景にはローポリ地形を使用 |
| **車庫の散乱** | アクティブなヤードに保管された数百本のアイドル編成 | 使わなくなったテスト用編成は無期限に放置せず削除する |

見た目のこだわりとゲームエンジンの制約のバランスを取ることで、前面展望（キャブビュー）カメラでの鑑賞中も、自慢のワールドを滑らかで快適に楽しむことができます。

## よくある質問（FAQ）

### Transport Fever 3 サンドボックスモードのプレイ中に実績を獲得できますか？
デフォルトでは、サンドボックスモードやクリエイティブなチートツールを有効にすると、通常のプラットフォーム実績は無効になります。ただしプレイヤーの報告によると、正確な設定状況によっては、特定のカスタムシナリオチャレンジやコミュニティのワークショップMODにより、一部のマイルストーン追跡を再度有効にできる場合があります。

### サンドボックスモードですべての歴史的車両にすぐアクセスするにはどうすればよいですか？
サンドボックスのワールド設定メニュー内で、「年代による車両制限（Era Vehicle Lock）」オプションをオフに切り替えます。これにより、あらゆる時代のすべての列車、バス、トラック、航空機、船舶が即座にアンロックされ、19世紀のクラシックな蒸気機関車と現代の超高速新幹線・弾丸列車を並べて運行できるようになります。

### 既存の標準セーブデータをサンドボックスモードのセーブデータに変換できますか？
はい、可能です。既存のキャリアまたはフリープレイのセーブファイルをロードし、起動前にカスタムゲームオプションから **Transport Fever 3 サンドボックスモード** をアクティブにできます。ただし、一度サンドボックスルールで変換して保存したデータは、通常の経済ルールに綺麗に戻せない場合があることに留意してください。

### 線路の上に都市が勝手に拡大して覆いかぶさるのを防ぐ最善の方法は何ですか？
サンドボックスモードの都市エディタツールを使用して、線路周辺の特定ゾーンを建設禁止区域として指定するか、線路の敷地境界に装飾フェンス、衝突判定のあるアセット、バッファー地形を配置して、自動的な都市建築の拡張を阻止してください。
