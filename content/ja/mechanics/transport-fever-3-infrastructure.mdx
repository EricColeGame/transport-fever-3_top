## Transport Fever 3 インフラの基礎原則

あらゆる輸送ネットワークは相互に接続された生命体のように機能し、たった1箇所の分岐器や貨物ヤードで発生したボトルネックがマップ全体へと波及することがあります。堅牢なシステムを構築するためには、線路やアスファルトを敷設し始める前に、明確な交通アーキテクチャの階層構造を確立しなければなりません。

現代のネットワークトポロジーにおける主目標は、速度、停車頻度、貨物プロファイルごとにトラフィックを明確に分離することです。低速な地方の石炭輸送列車と急行旅客列車を同一の複線に混在させると、原因不明の遅延やダイヤの連鎖的な崩壊を招く結果となります。優れた都市開発者は、二次的な地域フィーダー路線と並行して専用の高速回廊（トランクライン）を敷設し、それらを共有のマルチプラットフォームターミナルで接続しています。

```
[原材料産地 / 郊外] ---> (フィーダー網: 地方道路/地域鉄道)
                                  │
                                  ▼
                         [地域集約ハブ]
                                  │
                                  ▼
                   (基幹回廊: 高速鉄道 / 重量貨物線)
                                  │
                                  ▼
                       [中央複合ターミナル]
                                  │
                                  ▼
               [都市中心部 / 最終商業・工業配送エリア]
```

また、地形は路線の建設費用や運行速度に決定的な影響を与えます。山岳地帯を切り開いたり広い河川を渡ったりする際、無理な大規模造成を行うと莫大な初期費用がかかるだけでなく、長期的な盛り土の維持費が財務を圧迫します。自然の等高線、緩やかなスイッチバック登坂、段階的なトンネル建設を優先することが、序盤の資金ショートを防ぐ鉄則です。

| ネットワークトポロジー | 初期投資額 | 拡張性 | 最適なユースケース | 運用リスク |
| :--- | :--- | :--- | :--- | :--- |
| **ポイント・ツー・ポイント（直行型）** | 低 | 極めて低い | 序盤の孤立した原材料輸送ルート | 深刻な重複運行と空荷での復路 |
| **ハブ・アンド・スポーク** | 中 | 高い | 地域の旅客輸送網およびローカル貨物 | 中央ハブの過密とボトルネック化 |
| **トランク・アンド・フィーダー（基幹・支線型）** | 高 | 極めて高い | マップ横断の貨物大動脈と都市間輸送 | 初期建設費のオーバーヘッドが大きい |
| **分散型リンググリッド（環状網）** | 極めて高 | 最大 | 巨大都市の郊外バイパスと工業ループ線 | ルーティング判断と信号管理の複雑化 |

## 鉄道網エンジニアリング：分岐器、立体交差、および信号システム

鉄道建設は輸送ネットワークの収益の柱ですが、同時に最も壊滅的なグリッドロック（交通麻痺）を引き起こしやすい領域でもあります。線路を敷設する際、**Transport Fever 3のインフラ**では、曲線半径、分岐角度、信号の配置に関して厳格な規律が求められます。

### 信号プロトコルと閉塞区間の分割

信号の配置は、ネットワークの運行間隔（2本の列車を安全に隔てる最小時間差）を決定づけます。信号間の距離は、その閉塞区間を走行する最長列車の編成長に合わせて設定する必要があります。最長列車の全長よりも短い間隔で信号を設置してしまうと、最後尾車両が手前の閉塞境界を抜け切る前に先頭車両が次の信号を通過してしまい、後続列車に不必要な急ブレーキを作動させる原因となります。

```
不適切（信号間隔 < 列車の全長）:
[ 信号 ] ======= [ 列車編成 ] ======= [ 信号 ]  --> 誤った停止トリガーが発生
           <--- 列車が閉塞からはみ出す --->

最適（信号間隔 = 列車の全長 + 安全マージン）:
[ 信号 ] ============================== [ 信号 ]  --> スムーズな運行、最高速度を維持
             [ 列車編成全体 ]
```

複線回廊における単方向の閉塞信号は基本的な標準です。基本運行から高スループットな路線へとステップアップするには、複雑な分岐の手前に中間パス信号を配置し、ターミナルの出入り口ブロックには中間マーカーを一切置かないようにします。ダイヤモンドクロッシング（平面交差）の内部に直接信号を配置してはなりません。列車は出口側の閉塞が完全に空いている場合にのみ交差点へと進入すべきです。

### 立体交差と分岐の幾何構造

線路が別の線路を同一平面上で横切る平面交差は、中盤以降のネットワーク麻痺を引き起こす最大の要因です。重要な分岐点を立体交差（フライング・ジャンクションやバローイング・ジャンクション）に改修することで、交差支障を完全になくし、低速な貨物列車が下層に分岐する間も高速列車が上層を減速なしで駆け抜けることが可能になります。

| 分岐タイプ | スループット定格 | 建設フットプリント | コスト指数 | 主な障害発生点 |
| :--- | :--- | :--- | :--- | :--- |
| **平面ダイヤモンド交差** | 低（4本未満/分） | 最小 | 1.0x | 正面からのパス予約の競合 |
| **両渡り線（シーサスクロッシング）** | 中 | コンパクト | 1.8x | 同時進入時の待ち行列発生 |
| **立体交差（フライング・ジャンクション）** | 高（8本以上/分） | 大 | 4.2x | 高架橋およびアプローチ盛り土の高コスト |
| **トランペット型ジャンクション（鉄道）** | 極めて高 | 広大 | 5.5x | 長いアプローチ曲線による制動減速 |
| **立体交差型デルタ線（Wye）** | 最大 | 極めて広大 | 6.8x | 複雑な多層立体橋梁のクリアランス確保 |

分岐曲線を開始する前には、必ず150メートル以上の平坦な直線軌道を確保してください。下り勾配や急カーブの直後に設置された分岐器は、車両に激しいブレーキを強いることになり、走行モーメンタムを失わせ機関車の燃料消費を増大させます。物理演算やルーティングエンジンに関する開発元の最新アップデートについては、[Urban Games公式開発者ポータル](https://www.urbangames.com)で経路探索技術の詳細をご確認ください。

## 道路網トポロジー：都市部の渋滞対策

工業製品の供給や旅客の接続需要がピークに達するにつれて、都市中心部は急速に拡大します。都市のグリッド街路を放置していると、自家用車の増加と配達トラックの列によって、あっという間に市街地が麻痺してしまいます。都市の道路と郊外バイパスを適切に管理することは、貨物の円滑な流れを維持するために不可欠です。

```
[都市間高速道路 / フリーウェイ]
               │
               ▼  (高容量パーシャル・クローバーリーフ / トランペット型IC)
[幹線大通り: トラム中央分離帯付き6車線]
               │
               ▼  (ラウンドアバウト / 信号なしスリップレーン)
[集散道路: 配達ゾーン専用レーン付き4車線]
               │
               ▼  (右折イン / 右折アウト交差点)
[地域・住宅街路: 2車線低速アクセス道路]
```

道路の階層構造を最適化するには、「幹線道路（Arterial）」「集散道路（Collector）」「局地道路（Local）」を明確に区分する必要があります。幹線道路は地区間のノンストップ交通を担い、集散道路は近隣からの交通を集約し、局地道路は各住居や店舗の玄関口へと車両を分散させます。集散道路を挟まずに局地道路を直接幹線高速道路に接続すると、交差点で永久に解消しない渋滞列が発生します。

| 道路区分 | 目標速度帯 | 車線配分戦略 | 公共交通の統合 | 交差点優先度 |
| :--- | :--- | :--- | :--- | :--- |
| **都市間高速道路** | 100–130 km/h | 4–6車線（中央分離・立体交差） | なし（都市間急行バスのみ） | 完全立体交差ICのみ |
| **都市幹線道路** | 60–80 km/h | 中央トラム専用軌道付き4–6車線 | 中央走行型トラム/バス専用レーン | ラウンドアバウトまたは時差式信号 |
| **商業集散道路** | 50 km/h | 4車線（2車線公共/トラック、2車線一般） | 追い越しベイ付き路肩バス停 | 側道側に一時停止/譲れ標識 |
| **住宅地道路** | 30–40 km/h | 2車線（歩行者優先舗装） | 標準の路上停留所 | 制御なし右左折（出入りのみ） |

集散道路の回廊にバスおよび配送車両専用レーンを整備することで、一般車の渋滞から公共交通機関を守ることができます。都市の人口が数千人規模を超えたら、主要な地上バス路線を立体交差の高速トラム専用軌道や地下ライトレールトンネルへと移行させ、貴重な路面スペースを節約しましょう。

## 複合一貫輸送（インターモーダル）とモジュール式ハブ設計

輸送モードを孤立させて運用すると、深刻な物流の非効率が生じます。高効率なロジスティクスはシームレスな乗り継ぎ・積み替えにかかっています。鉄道は陸上の長距離大量輸送に秀で、船舶は最低のコストで莫大な量を運び、航空機は極端な地理的隔たりを結び、トラックはラストワンマイルのきめ細やかな配送を担います。

```
       [鉄道貨物（到着）]              [コンテナ船ドック]
                 │                              │
                 ▼                              ▼
      ┌──────────────────────────────────────────────────┐
      │             中央複合一貫物流ヤード               │
      │   - 共有の内部集荷・受取バッファ                 │
      │   - 対面乗り換え・積み替え用レール               │
      │   - スルー型（通り抜け）仕分け・積載ベイ         │
      └──────────────────────────────────────────────────┘
                                │
                                ▼
                     [ラストワンマイル配送車隊]
                                │
                                ▼
                       [都市商業マーケット]
```

統合された複合ターミナルによって拠点を近代化すれば、貨物の滞留時間を最小限に抑えることができます。モジュール式プラットフォームは、到着した木材、穀物、加工ツールなどが二次的なトラック輸送を介することなく、待機中の配送車両に即座に積み替えられるよう、バランスの取れた集約範囲（キャッチメントエリア）で構成する必要があります。

| ハブ構成タイプ | スループット効率 | 敷地の柔軟性 | 対応する積み替えモード | 最適な配置戦略 |
| :--- | :--- | :--- | :--- | :--- |
| **行き止まり式ターミナル** | 中 | 制限あり | 鉄道 ＋ 道路 ＋ 都市トラム | 行き止まり地形の都市中心部 |
| **スルー型モジュール式ヤード** | 極めて高 | 線形 / 拡張可能 | 高速鉄道 ＋ 地域鉄道 ＋ バス | 自然な都市間輸送軸の沿線 |
| **臨海レール・水運ポート** | 最大（バルク貨物） | 水辺に依存 | 河川バージ ＋ 貨物船 ＋ 重量貨物鉄道 | 水深の深い河口や海洋の湾岸部 |
| **空陸複合貨物ターミナル** | 高（高付加価値品） | 広大な平地が必要 | 長距離航空 ＋ 高速貨物輸送 | 都市圏外縁の広大な田園平野部 |

モジュール式貨物駅を設計する際は、行き止まり式のバック進入ベイではなく、通り抜け可能な「スルー型トラックベイ」を設置してください。バックで進入するプラットフォームは、トラックが切り返しを行うたびに微小な遅延を生み、収穫期や生産ピーク時に進入道路へと続く大渋滞を引き起こす原因となります。

## インフラの保守・更新と長期的な拡張性

都市計画者が陥りがちな最大の罠は、線路や架線の継続的な維持費を考慮せずに急速にネットワークを広げすぎてしまうことです。敷設されたすべてのインフラピースには、車両が走っているかどうかにかかわらず、毎日の維持費が発生します。使われていないバイパス線や空のプラットフォームを抱えた過剰規模のネットワークは、不況期に静かに資金をすり減らしていきます。

```
初期フェーズ:
[単線路線: 低速、木まくらぎ軌道]  (初期投資小、車両運用コスト高)
                   │
                   ▼  (輸送量が容量の75%に到達)
中期フェーズ:
[複線回廊: 120 km/h 木まくらぎ軌道] (適度な維持費、バランスの良い収益)
                   │
                   ▼  (郊外の発展および重量輸送需要の増大)
成熟フェーズ:
[複々線電化幹線: 200+ km/h コンクリート軌道] (高い固定維持費、最低のユニットコスト)
```

段階的な近代化戦略を採用することで、将来の拡張への備えを維持しつつ、日々の運用予算を守ることができます。単線のディーゼル路線を複線の電化システムへと改修するのは、路線の利用率が閉塞区間の最大容量の70〜80%程度に達した時点に留めるべきです。

| アセット分類 | 維持費プロファイル | 改修のトリガー条件 | アップグレード前の前提条件 | 想定投資回収期間 (ROI) |
| :--- | :--- | :--- | :--- | :--- |
| **標準木まくらぎ軌道** | 最小限の基本維持費 | 初期の路線建設時 | なし | 即時 |
| **高速コンクリート軌道** | 中程度の維持費 (+45%) | 路線制限速度が車両最高速度を下回る | カーブの緩和、緩やかな勾配 | 中期（運用年数2〜4年） |
| **軌道電化（架線）** | 高い固定維持費 (+60%) | ディーゼル車隊の運行・燃料コスト高大 | 高密度の運行頻度 | 早期（運用年数1〜2年） |
| **吊り橋および大深度トンネル** | 極めて高い維持費 (+250%) | 渓谷・海峡のボトルネックによる容量限界 | 複数路線による安定した収益基盤 | 長期（運用年数5〜10年） |
| **自動化された最新分岐器** | わずかな維持費増 | 分岐待ちの遅延が30秒を超える場合 | 信号の再配置 | 即時 |

シーズンあたり1〜2本の列車しか走っていない段階で早すぎる電化を行うと、固定維持費がかさみ運賃収入の利益が吹き飛びます。毎月、路線の積載統計をチェックしましょう。進入信号の手前で列車の待ち行列が発生したり、駅で恒常的な貨物のあふれが発生したりした段階で、プラットフォームの延伸やコンクリート軌道への更新に資金を投じるのが理想的です。

## 高度なネットワーク計画テクニック

コミュニティの検証によって、過密なマップであってもクリーンな運行フローを維持できる高度なレイアウト戦略がいくつか確立されています。

*   **サイフォンプラットフォーム（待避構造）:** 複数プラットフォームを持つ旅客駅を管理する場合、外側のループ線に各駅停車の通勤列車を割り当て、中央を通過するノンストップの追越し線を本線として直進させます。この配置により、停車中の列車が後続の急行の進行を妨げることがなくなります。
*   **セグメント化された貨物待機ヤード:** 主要な工業用降ろし線の手前に、並行する専用の待避側線を敷設します。加工工場の内部ストレージが満杯になった場合でも、進入列車は本線を塞ぐことなく待避線内で安全に待機できます。
*   **バルーン・リバーサルループ（ラケット線）:** スペースが限られた過密な旅客ターミナルでは、駅の終端から地下に潜るバルーン状の反転ループ線を設けることで、列車が出発線を横切ることなく進行方向を反転でき、発着頻度を大幅に高めることができます。
*   **ステップ状の段階的勾配設計:** 急な斜面を登る場合、線路を階段状に敷設します。つまり、2.5%の登坂区間と完全な平坦区間を交互に設けます。これにより、重量貨物編成が次の上り勾配に挑む前に平坦部で速度を回復させることができます。

これらの構造要素を綿密に計画しておくことで、ゲーム内の年代が現代へと進んでも、物流の屋台骨を揺るぎなくスムーズに稼働させ続けることが可能になります。

## よくある質問（FAQ）

### Transport Fever 3のインフラで交差衝突や分岐でのデッドロック（詰まり）を解消するにはどうすればよいですか？
分岐での詰まりは、中間信号が交差点に近すぎる場所に設置され、列車が交差の真ん中で停止してしまうことで発生します。これを解決するには、混雑する平面交差を緩やかなアプローチ橋を用いた立体交差（フライング・ジャンクション）へと改修してください。また、進入手前にパス信号を適切に配置し、出口側には列車1編成全体の長さを超える空き線路が確保できるまで信号を置かないように徹底してください。

### 貨物積み替え駅の最も効率的なレイアウトは何ですか？
最も効率的な貨物レイアウトは、鉄道の貨物プラットフォームのすぐ隣にモジュール式の通り抜け型（スルー型）トラックベイを配置することです。トラックがいったんバックしないと出られない行き止まり型のプラットフォームは避けてください。原材料の搬入ベイと最終製品の搬出ベイを同一の集約範囲（キャッチメント内）にまとめることで、鉄道と道路の間で移動時間をゼロにした即時積み替えが可能になります。

### ディーゼル機関車から軌道電化へ切り替えるべきタイミングはいつですか？
電化には多額の継続維持費がかかるため、高密度の回廊でのみ採算が合います。1路線あたり最低でも3〜4本の列車が常時稼働し、旅客または貨物の需要から高加速な電車・電気機関車の導入が求められるようになった段階で、基幹路線の架線敷設に着手してください。運行頻度の低い閑散とした支線フィーダーには、ディーゼル動力のまま維持するのが経済的です。

### 都市の渋滞によってバス路線が完全にストップしてしまうのを防ぐにはどうすればよいですか？
一般車の渋滞から公共交通を守るため、都市の集散道路や幹線道路沿いにバス・トラム専用レーンを割り当ててください。また、拡大する都市の周囲に環状バイパス道路を建設して長距離トラックの交通を都心部から迂回させ、混雑する中心街の交差点をコンパクトなラウンドアバウトに置き換えることで、車の流れを止めることなくスムーズに流すことができます。
