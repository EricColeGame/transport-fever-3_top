## 貨物および生産エコシステムの基本メカニズム

このシミュレーションの産業基盤は、プッシュ型（供給主導）ではなくプル型（需要主導）の経済エンジンによって駆動しています。一次採取場は、単に隣にトラックターミナルが置かれたからといって資源を生産するわけではありません。その資源を必要とする消費者まで直接つながる、途切れのないエンドツーエンドの商流チェーンが存在して初めて稼働します。ルート上のいずれかのリンクで容量不足が発生したり、ターミナルで深刻な渋滞が起きたり、有効な都市の目的地ゾーンに接続できなかったりすると、上流のチェーン全体が減速または停止します。

```
[原材料採取場] ──(大量貨物)──> [加工施設] ──(中間財)──> [工場] ──(完成品)──> [都市の商業/工業ゾーン]
```

各産業施設は段階的な生産ティア（階層）に従って稼働します。ネットワークが原材料を確実に納入し、出荷用プラットフォームの滞留を解消し続けると、産業のレベルが上がり、より高い生産上限が解放されます。逆に、積載プラットフォームが長期間飽和したまま放置されたり、配送頻度が許容値を下回ったりすると、産業施設は目標出荷枠を引き下げ（ダウングレード）てしまいます。

### 生産ティアと工場の挙動

各産業は、内部のパフォーマンス指標を通じてプレイヤーの物流ネットワークを監視しています。高い輸送評価を維持するには、車両の発車間隔（ヘッドウェイ）を短く保ち、プラットフォームの有効長を列車の編成長と一致させ、屋根のない野積みプラットフォーム上での貨物劣化を防ぐ必要があります。

| 生産ティア | 標準生産レート | 必要原材料 | アップグレード発生条件 | ダウングレードのリスク要因 |
| :--- | :--- | :--- | :--- | :--- |
| **ティア1（基本）** | 100〜200ユニット/年 | 原材料 1種 | 継続出荷率 > 70% | 2か月連続で出荷ゼロ |
| **ティア2（拡張）** | 200〜400ユニット/年 | 原材料/半製品 2種 | 継続出荷率 > 80% | 駅ターミナルの過負荷 > 30日 |
| **ティア3（高度）** | 400〜800ユニット/年 | 複数原料のバランス供給 | 安定した配送達成率 85%以上 | 出荷保管庫の完全飽和 |
| **ティア4（メガハブ）**| 800〜1600+ユニット/年 | 高密度な複数供給源 | 一貫した路線信頼性 90%以上 | 運行頻度が許容閾値を下回る |

プレイヤーの経験則として、採石場、鉄鉱石鉱山、穀物農場などの上流の原材料拠点は、二次加工工場がそれらの材料を積極的に消費している場合にのみ規模を拡大します。スラグや建築資材を拡大中の都市へ輸送する列車がないために製鉄所が満杯になった場合、その製鉄所に供給している鉄鉱石鉱山や炭鉱も、反応して採取枠を絞り込んでしまいます。

## Transport Fever 3 完全サプライチェーンマップ

複雑な生産ネットワークを的確に運用するには、どの原材料を組み合わせれば高付加価値な貨物が生まれるかを把握することが不可欠です。初期の時代には基本的な建築資材や食料が求められますが、近代・現代になると都市の人口増加を支えるために高度な電子機器、燃料、機械、消費財が必要になります。

大規模な**transport fever 3 industries cargo**ネットワークを管理する際は、変換比率（歩留まり）を常に意識しなければなりません。1つの加工施設で完成品の木箱を1つ生み出すために、複数ユニットの原材料が必要になるケースが多いため、上流のフィーダー（支線）輸送は、下流の完成品配送よりも2倍から3倍の発車頻度で運行する必要があります。

| 貨物チェーン区分 | 一次資源（原材料） | 中間製品 | 完成品（消費財・工業製品） | 標準的な貨物変換比率 |
| :--- | :--- | :--- | :--- | :--- |
| **建築資材** | 石材、スラグ、砂 | 砂利、セメント | 建築資材 | 石材 2 または スラグ 1 : 建築資材 1 |
| **食品・農業** | 穀物、家畜 | 小麦粉、加工肉 | 食料品 | 穀物 2 または 家畜 2 : 食料 1 |
| **重化学工業** | 鉄鉱石、石炭 | 鋼鉄、粗製プラスチック | 機械・工具 | 鉄 2 + 石炭 2 : 鋼鉄 1 -> 機械 1 |
| **石油・石油化学**| 原油、化学薬品 | 精製油、ポリマー | 燃料、プラスチック製品 | 原油 2 : 精製油 1 -> 燃料 1 |
| **高級消費財** | 原木、木材、鋼鉄 | 板材、接合具（金物） | 商品（消費財） | 板材 2 + 鋼鉄 1 : 商品 1 |

高収益な変換フローを維持するためには、中間積載物に適した貨車タイプを正しく割り当てる必要があります。無蓋車（ホッパー車）は石炭や石材の運搬に最適ですが、デリケートな食料品、工具、完成品貨物には有蓋車（ボックスカー）や幌付き貨車が必須です。1つの編成に互換性のない貨物スペースを混載させると、車両の積載効率が大幅に低下し、利益率を損なう原因になります。

## 駅、受容範囲（キャッチメントエリア）、ハブ乗り継ぎの最適化

貨物物流で頻繁に発生する障害のひとつが、駅の受容範囲（キャッチメントエリア）の設定ミスです。すべての貨物駅、港湾ターミナル、鉄道側線には固有の有効半径が存在します。正しく配置されると、白くハイライトされた受容エリアによって、近隣のどの建物や加工センターがプラットフォームにアクティブに接続されているかが示されます。

効率的な貨物流通システムを構築するため、多くのプレイヤーは公式の[Urban Games 開発者ポータル](https://www.urbangames.com/)で公開されている技術ガイドラインを参照しています。ここでは経路探索ルーチン、駅の受容範囲計算、貨物ターミナルのシミュレーション仕様が詳しく解説されています。

```
       [原材料鉱山]
           │ (短距離道路フィーダー)
           ▼
    ┌──────────────┐
    │  貨物ハブ A  │
    └──────┬───────┘
           │ (重量幹線複線鉄道)
           ▼
    ┌──────────────┐
    │  貨物ハブ B  │
    └──────┬───────┘
           ├──(道路配送)──> 都市中心部（商業ゾーン）
           └──(支線鉄道)──> 二次製品製造工場
```

### 専用ターミナルと容量管理

競合する複数の路線で貨物プラットフォームを共用すると、致命的なボトルネックが発生します。2つの貨物路線が単一の鉄道側線を共有している場合、プラットフォームの保管スペースはそれぞれの貨物割り当て分に分割されます。路線Aで滞留が発生すると、積み上がったパレットが路線Bの待機レーンにまで溢れ出し、ターミナル全体が麻痺してしまいます。

| 輸送モード | 最適輸送距離 | プラットフォーム容量 | 投資コスト | トンマイルあたりの運行コスト |
| :--- | :--- | :--- | :--- | :--- |
| **道路トラック** | 0.5〜3 km（近距離フィーダー） | 低（バース増設で拡張可） | 初期投資は最小限 | 車両単位で見ると高い |
| **一般鉄道** | 3〜25 km（地域幹線） | 極めて高い（モジュール拡張） | インフラ建設費が高い | 高積載率時は極めて低い |
| **はしけ / 内航船**| 5〜40 km（航行可能水路） | 膨大なバルク輸送能力 | 港湾設備費用は中程度 | 非常に低い |
| **航空貨物** | 20+ km（長距離・高付加価値品） | 中程度（滑走路の制約あり） | 初期投資が天文学的に高額 | 極めて高い |

各路線には、常に専用の線路とモジュール式貨物プラットフォームを割り当てるようにしてください。追加の貨物倉庫、荷受ドック、拡張ストレージモジュールを設置することで、ターミナルの最大バッファ容量を直接拡大できます。このバッファがあれば、列車が駅間を走行している最中に生産施設がストップしてしまう事態を防ぐことができます。

## 高度なルートバランシング：デッドヘッド（空荷走行）の排除

貨物の収益性を損なう最大の要因は「デッドヘッド」、すなわち復路を空荷のまま走らせることです。16両編成のホッパー車が北部の山岳鉱山から沿岸の製鉄所まで鉄鉱石を運び、帰路を完全に空の状態で戻ってくる場合、その列車の稼働時間の50%は収益を生まないまま燃料を消費していることになります。

高効率な**transport fever 3 industries cargo**回廊を設計するには、三角ルートや環状（クローズドループ）ネットワークを構築する必要があります。停車駅を戦略的に設定することで、往路で粗鉱を運び、近隣の施設で中間財を積み込み、復路で建築資材や消費財を最初の地域へと運び戻す運行が可能になります。

```
              [鉄鉱石鉱山]
               ▲           │
 (空荷または   │           │ (鉄鉱石を輸送)
  復路物資)    │           ▼
         [採石場/建材] ◄─── [製鉄所]
                     (スラグ/鋼鉄を輸送)
```

### ルートの非効率性に対する診断と解決策

コミュニティからの報告では、路線網を急激に拡張した際に突然生産量が低下する問題がよく見られます。診断チェックリストを活用することで、トラブルの原因が駅の設定ミス、車両の不適合、あるいは都市部への配送詰まりのいずれにあるかを素早く特定できます。

| 確認された症状 | システムの根本的なボトルネック | 推奨される診断・改善アクション | 優先度 |
| :--- | :--- | :--- | :--- |
| **工場の生産量が頭打ち** | 都市の消費ゾーンへの供給が飽和している | 2番目、3番目の都市へ支線を伸ばす | 最重要 |
| **駅の過負荷アイコン表示** | 列車の積載量または運行頻度が不足 | 編成を長くするか、途中に列車を増発する | 高 |
| **貨物が全く発生しない** | 市場へのサプライチェーンが未完成 | 最終配送先から都市の商業/工業ゾーンへの経路を確認 | 最重要 |
| **路線が赤字で運行中** | 長距離の空荷走行（デッドヘッド）の発生 | 汎用積載荷台の導入または三角ループの編成 | 中 |
| **深刻な道路交通渋滞** | トラック配送レーンが過密状態 | 直通トラック輸送を鉄道乗り継ぎハブへ置き換える | 高 |

汎用荷台や多種貨物対応の荷台を備えた車両を採用すると、ルート運用の柔軟性が最大限に高まります。専用のタンク車や長物車の方が積み込みアニメーションは若干早いものの、幌カバーを自動で切り替えて穀物、石炭、加工品のいずれも積載できるモジュール式貨車は、運行の収益性を劇的に引き上げてくれます。

## ステップバイステップ戦略：初期から終盤までの黒字貨物ネットワーク構築

持続可能な貨物帝国を築くには、技術の進化に合わせてロジスティクス戦略を適応させていく必要があります。蒸気機関や馬車輸送の時代に円滑に機能していたシステムでも、現代の大重量な電気・ディーゼル機関車の運用下では破綻してしまうことがあります。

長期的な**transport fever 3 industries cargo**戦略を段階的なフェーズに分けて整理することで、基幹配送ラインが利益を生み出す前に資本が枯渇してしまう事態を防ぐことができます。

| ゲームフェーズ | 戦略的優先事項 | 主力車両タイプ | 推奨ネットワーク設計 | ターゲット収益源 |
| :--- | :--- | :--- | :--- | :--- |
| **初期（黎明期）** | シンプルな2拠点間の原料ループ | 馬車、初期型蒸気機関車 | ポイント・ツー・ポイント直行線 | 食料、建築資材 |
| **中期（産業化期）** | 複数工場を連携させた工業化 | 大型蒸気機関、初期ディーゼル | 中継駅を備えたハブ＆スポーク | 鋼鉄、燃料、機械 |
| **近代・現代** | 高密度な複数都市への供給網 | 高出力電気機関車 | 複合一貫（インターモーダル）貨物駅 | 多資源の完成品、電子機器 |
| **エンドゲーム** | マップ全域にまたがる広域ループ | 超大型貨物列車、ダブルスタック | 完全立体交差の専用貨物回廊 | 全都市の消費需要100%充足 |

### フェーズ1：初期キャッシュフローの確保
まずは近距離で利益率の高い、単一資源の加工ルートのみに集中します。農場を近隣の食品加工工場に直結させ、完成した食品をすぐそばの密集した市街地へ届けることで、ゲーム序盤から安定した利益が得られます。初期の数十年は線路維持費を抑えるため、鉄道の敷設距離は短く保ちましょう。

### フェーズ2：産業基幹ラインの構築
都市が成長してきたら、単純な拠点間輸送から地域流通センター方式へと移行します。主要な工場の近くに中央仕分けハブを設置してください。フィーダー線路を使って石炭、鉄、原油をハブに集約し、完成した機械類を長大な多両編成列車で外周の各供給ポイントへ配送します。

### フェーズ3：都市部への完全統合
ゲーム終盤の物流では、都市部でのスムーズな積み替えが欠かせません。用地の制約、騒音、交通渋滞の観点から、重量貨物列車を中心市街地へ直接乗り入れさせるべきではありません。大動脈の鉄道は都市境界の外にある複合インターモーダル駅で終点とし、そこから電気配送バンに貨物を載せ替えて商業・工業ブロック全体へ小口配送します。

## よくある質問（FAQ）

### Transport Fever 3の産業・貨物ネットワークで工場が生産を開始しないのはなぜですか？
ほとんどの場合、完成品の行き先が存在しないことが原因です。下流のサプライチェーンをすべて点検してください。最終配送ターミナルの受容範囲が都市内の商業または工業需要をカバーしているか、ルート上の車両が指定の貨物タイプに対応しているか、経由地のプラットフォームが無関係な貨物で完全に塞がれていないかを確認しましょう。

### プラットフォームの過負荷は産業の生産評価にどう影響しますか？
駅のプラットフォームが最大保管容量に達すると、荷物の劣化や破棄が始まり、関連する産業で「配送遅延・失敗」が発生します。上流の工場は自社の出荷物が効率的に届けられていないと判断し、プラットフォームの混雑が解消されるまで生産ティアをダウングレードさせてしまいます。

### 同じ線路上で旅客列車と貨物列車を混在運行させるべきですか？
資金が限られる最序盤であれば線路の共用はコスト削減になりますが、交通量の多い幹線では旅客回廊と貨物回廊を完全に分離するべきです。貨物列車は一般に編成が長く、加速が鈍く、重量も格段に重くなります。低速な貨物列車と高速な旅客列車が混在すると深刻な運行ダイヤの乱れが生じ、双方の路線の運行頻度と収益性が悪化します。

### 1つの工場から複数の都市へ効率よく物資を供給するにはどうすればよいですか？
中央工場のすぐ隣に専用の配送ステーションを構築してください。生産プラントからその仕分けハブへは大容量のシャトル列車をピストン運行させ、ハブから各都市へ向けて独立した支線を伸ばします。これにより、特定の都市での局所的な需要急増を隔離し、製造元のボトルネックを作ることなく各都市向けの車両数を柔軟に調整できるようになります。
