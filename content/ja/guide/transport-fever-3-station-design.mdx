広大な輸送帝国において、ネットワークの鉄道ハブをマスターすることは、ゲーム終盤の交通麻痺（グリッドロック）を防ぐための最も重要な要素です。最適化された**Transport Fever 3の駅設計**がなければ、急速に拡大する都市と急増する産業路線によって、最も利用頻度の高いターミナル駅は壊滅的な遅延に見舞われ、すぐに機能不全に陥ります。この包括的なガイドでは、車両をスムーズに運行させ続けるためのモジュール式レイアウト、貨物バイパス経路、そして高スループットな駅スロートの設計など、効率的な**Transport Fever 3の駅設計**の核となるメカニズムを詳しく解説します。

収益性の高い交通帝国を築くには、建設コストと長期的な輸送処理能力のバランスを取る必要があります。人里離れた貨物デポを敷設する場合でも、都心部の8線マルチモーダル交通センターを構築する場合でも、緻密な駅設計を行うことで、列車が進行現示（青信号）を待つ時間を最小限に抑え、乗客および貨物輸送による収益創出時間を最大化できます。

## モジュール式駅アーキテクチャの基本原則

現代の輸送シミュレーションにおけるネットワーク計画の基盤は、モジュール設計の柔軟性にあります。地域の需要拡大に伴ってすぐに陳腐化してしまう固定型の既製ターミナルを設置するのではなく、モジュール構造を採用することで、ホームの長さや線路の割り当て、歩行者のアクセスポイントを柔軟に変更できるようになります。

レイアウトを計画する際、設計者はダイレクトな進入経路を最優先し、列車がホーム終端（車止め）に到達する前に線路交差の競合を排除しなければなりません。

| コンポーネントの種類 | 主な機能 | 戦略的検討事項 | 推奨される初期配置 |
| :--- | :--- | :--- | :--- |
| **旅客ホーム** | 通勤・通学客の乗降 | 最長の旅客列車と同等以上の長さが必要 | 160m〜240mのモジュールブロック |
| **貨物プラットフォーム** | 貨物の積み替えおよび一時保管 | 隣接する積載ベイと道路接続が必須 | 溢れを防ぐため240m〜320m |
| **通過線** | ターミナルを無停車で通過 | 急行列車によるホームの混雑を回避 | プラットフォームペアの中央線路 |
| **地下道 / 跨線橋** | 分割された島式ホーム間の歩行者動線 | 通勤客の経路ボトルネックを防止 | 旅客ホーム沿いに80m間隔 |
| **ターミナル構内スロート** | 本線と各ホームを接続する分岐器 | 適切な信号閉塞区間の長さが必要 | 車止めから最低でも列車長の1.5倍以上 |

プレイヤーの経験やコミュニティの報告によると、将来の拡張を見越したバッファを設けてホームを設計することで、将来的な大規模解体費用を大幅に節約できることが一貫して実証されています。初期の駅建設時に少なくとも線路と平行に2タイルのバッファスペースを残しておけば、隣接する市街地を壊すことなく、乗客用の待合棟、貨物積載エプロン、増設線路を追加できます。

## 旅客ハブのレイアウト：頭端式（ターミナル）駅 vs 通過式駅

行き止まりの頭端式駅か、通過式（貫通式）駅のどちらを選択するかは、旅客路線の運行リズムを大きく左右します。頭端式駅は、地形的制約や高密度の市街地によって反対側へのトンネル掘削がコスト的に難しい、歴史的な高密度中心街に最適です。しかし、進入した列車は対向するスロートの線路を横切って折り返す必要があるため、必然的に処理能力が制限されます。

対照的に、通過式駅は常に前進する勢いを維持できます。列車が進入して乗客を乗降させ、後続列車の進入経路を塞ぐことなく反対側の閉塞区間へと加速して出発していきます。

| 特徴の比較 | 頭端式ターミナル駅 | 通過式駅 | 島式ホーム通過型ハブ |
| :--- | :--- | :--- | :--- |
| **占有スペース** | 奥行きはコンパクト、横幅が広い | 前後に長い直線的なフットプリント | 適度な直線的フットプリント |
| **最大処理能力** | 中（スロートが折り返し頻度を制限） | 非常に高い（一方向の流れ） | 最高（共有プラットフォームアクセス） |
| **線路の複雑さ** | 複雑なシーサスクロッシングが必要 | 単純な直線的ハシゴ状分岐 | 立体交差によるハシゴ状ジャンクション |
| **都市との統合** | 都市の境界部に配置しやすい | 都市開発エリアを二分する | 高架線または掘割式の線路に適する |
| **最適な用途** | 通勤路線の終点、郊外の枝線 | 都市間幹線、高速鉄道 | 中央マルチモーダル乗換駅 |

優れた通過型ハブを設計するには、2本の平行する線路が中央の旅客コンコースを共有する「島式ホーム」を導入しましょう。このレイアウトにより、歩行者用の階段やエレベーターモジュールに必要なインフラを半減させつつ、郊外のフィーダー路線と本線急行列車の間でのスムーズな乗り換えを実現できます。

## 高度な貨物ターミナル設計と貨物ステージング

貨物ターミナルは、旅客駅とは根本的に異なるロジスティクス上の圧力下で動作します。貨物の搬出量は大量のバッチ単位で急増し、ターミナルの保管容量が上限に達すると、プラットフォームはそれ以上の生産品の受け入れを拒否します。したがって、信頼性の高い**Transport Fever 3の駅設計**において、貨物駅には専用の増設保管ベイと分離された道路車両積み込みエリアの確保が不可欠です。

産業用列車の長さは旅客列車の編成を上回ることがよくあります。320メートルの鉱石列車が160メートルのホームに停車すると、荷降ろし時間が劇的に増加し、産業回廊全体に深刻なボトルネックを引き起こします。

```
貨物幹線回廊
══════════════╦══════════════════════════════════════╦══════════════
              ║  [進入スロート：一方向ハシゴ状分岐]   ║
              ╠══════════════════════════════════════╣
              ║ 1番線：ホームA（粗鉱石）             ║
              ║ 2番線：ホームB（精製鋼鉄）           ║
              ║ 3番線：高速貨物通過線                ║
              ║ 4番線：待避・留置線 / ヤード         ║
              ╠══════════════════════════════════════╣
              ║  [出発スロート：立体交差]            ║
══════════════╩══════════════════════════════════════╩══════════════
```

貨物の滞留を防ぐため、次の4段階のステージング手法を活用してください：

1. **最大編成長の算出**: コンクリートを敷設する前に、運用予定の最長重量貨物列車の長さを測定し、機関車と貨車の長さにホームの長さを合わせます。
2. **ホームごとの貨物種別の分離**: 石炭や石材などの大量輸送原材料と、機械や工具などの少量完成品で同じ線路を共有させてはなりません。
3. **専用バイパスループの構築**: 車庫（デポ）間を回送する空の列車が重要な積み込み枠を占有しないよう、信号のない機回し・バイパス線を設置します。
4. **道路配送ループの統合**: 鉄道貨物プラットフォームに直接隣接してトラックステーションを配置し、重量鉄道から地方都市の配達バンへの即時積み替えを可能にします。

| 貨物駅の構成 | 平均停車時間 | 拡張の柔軟性 | ボトルネックのリスク | 主な適正貨物 |
| :--- | :--- | :--- | :--- | :--- |
| **片面単線ベイ** | 長い（90秒以上） | 低い | 高負荷時に深刻 | 低ティアの農業資材 |
| **複線島式貨物ホーム** | 中程度（45〜60秒） | 高い | バイパス線があれば極小 | 複合工業団地 |
| **ループ通過式（Ro-Ro）ターミナル** | 最短（20〜30秒） | 中程度 | 極めて低い | 原材料専用サプライチェーン |
| **統合型マルチモーダルヤード** | 変動あり | 非常に高い | 中程度（緻密な経路設定が必要） | 地域物流ハブセンター |

## ジャンクション設計とスロートの信号工学

どれほど美しく設計された旅客・貨物ターミナルであっても、駅への進入スロートの信号配置が不適切であれば破綻します。複線の本線から複数のホームへと分岐・接続する駅スロートは、交通ネットワークにおいて最も頻繁にボトルネックが発生する箇所です。

スロート設計の第一原則は「完全な分離」です。交通量が多い場合、平面交差（ダイヤモンドクロッシング）上で進入列車と出発列車の進路を決して交差させてはなりません。緩やかな跨線橋（フライオーバー）やアンダーパス（立体交差）を活用することで、進路競合チェックを排除し、進入線を常にクリアな状態に保てます。

| ジャンクション形式 | 信号密度 | 速度維持 | 建設費用 | 処理可能輸送量 |
| :--- | :--- | :--- | :--- | :--- |
| **平面シーサスクロッシング** | 低（単一のマスター閉塞） | 低（30〜40 km/h） | 非常に安価 | 12列車/時 未満 |
| **千鳥配置ハシゴ状分岐** | 中（独立閉塞区間） | 中程度（60 km/h） | 普通 | 12〜24列車/時 |
| **立体交差フライングジャンクション** | 高（連続進路閉塞） | 本線最高速度を維持 | 高価 | 40列車/時 以上 |
| **トランペット型ループ** | 最小（一方向連続） | 中〜高 | 広大な用地が必要 | 連続的な一方向流 |

駅進入部に信号を配置する際、分岐器の密集区間の真ん中に通常の閉塞信号機を配置することは避けてください。ジャンクションスロートの途中に置かれた信号で列車が停止すると、背後の他の路線すべてを塞いでしまいます。連動分岐器アレイ全体を単一のクリアゾーンとして維持し、進入信号機は最初の分岐器の手前直前に、ホーム出発信号機は各ホームデッキの終端直前に配置しましょう。シミュレーションの仕様に関する公式アップデートやゲームドキュメントの詳細は、[Urban Games公式サイト](https://www.urbangames.com/)の開発者リソースを参照してください。

## マルチモーダルな都市交通の統合：鉄道、トラム、バスの接続

鉄道ターミナルは単独では繁栄できません。多くの乗客を獲得するには包括的な都市交通の統合が必要であり、遠方の町から到着した通勤客が市営バス、トラム、地下鉄ネットワークにシームレスに乗り換えられるようにしなければなりません。まとまりのある**Transport Fever 3の駅設計**を実施するということは、鉄道ターミナルを階層化された地域交通ネットワークの中心的な「心臓部」として扱うことを意味します。

プレイヤーの経験やコミュニティの検証では、鉄道駅コンコースの直接の徒歩圏内に市営道路の停留所を配置することの重要性が強調されています。歩行者が複数の車道を横断しなければならない場合、移動時間が跳ね上がり、シミュレーション内の市民は公共交通機関よりも自家用車を選択するようになります。

| 都市交通レイヤー | サービス役割 | 鉄道駅に対する配置 | ベストプラクティスとなる間隔 |
| :--- | :--- | :--- | :--- |
| **近郊鉄道 / 都市間鉄道** | 地域幹線輸送 | 中央駅の中核ホーム | 都市間（長距離） |
| **都市トラム路線** | 高密度動脈ループ | 駅前広場ループまたは高架下・地下停留所 | 250m〜350m間隔 |
| **ローカルフィーダーバス** | 郊外住宅地の収集 | 駅前外周プラザのリングベイ | 150m〜200m間隔 |
| **歩行者専用通路** | ハブから商業エリアへの直結動線 | 高架ペデストリアンデッキおよび専用連絡口 | 中心街へ直結 |

都市交通の統合を最適化するには、次のステップに従ってください：

1. **歩行者用駅前広場の構築**: 駅の出入口を歩行者専用広場で囲み、メインエントランスの真正面に渋滞しやすい一般車両用道路を配置しないようにします。
2. **一方通行ループ式トラムターミナルの建設**: 行き止まり式のトラム折り返し地点を避け、一方通行のループ線を設置します。これにより、一般車両が路面電車の軌道を塞ぐのを防止できます。
3. **キス・アンド・ライド型バスベイの設置**: 乗り換え路線が荷降ろし中の車両の後ろに列を作らないよう、複数の乗降スペースを備えたスルー型のバスベイを整備します。
4. **地下歩道の整備**: 駅の収容力を拡張するためにホームを増設する際は、外側の旅客デッキを地下道で市街地の歩道に直結させ、歩行者の混雑を均等に分散させます。

## 駅の最適化チェックリストとトラブルシューティング

ホームに警告アイコンが点灯したり、列車が外方信号の手前で停止したまま動かなくなったりした場合は、この最適化チェックリストに沿って体系的にスループットの制約原因を特定・解消してください。

| 症状 | 根本原因 | 即効性のある対処法 | 長期的な工学的解決策 |
| :--- | :--- | :--- | :--- |
| **列車が進路を待っている** | スロート交差部での進路競合 | スロート区間の境界に信号機を再配置 | 立体交差フライングジャンクションを建設 |
| **ホームで貨物が消滅（腐敗）する** | プラットフォームの保管上限超過 | モジュール式貨物保管庫を追加 | より長い列車を投入するか発車間隔を短縮 |
| **乗客の乗車が遅い** | ホームが狭すぎる、または混雑している | 2つ目の島式ホームや階段を追加 | 複数改札を備えた旅客コンコースを建設 |
| **駅前での交通渋滞** | 市街地道路上でのバスの行列 | 停留所を道路外の交通ループ内に移設 | バス・トラム専用レーンを整備 |
| **駅付近での本線速度低下** | ホームへの進入曲線・分岐器がきつい | 滑らかな線形ジオメトリで分岐器を再敷設 | 高速分岐器モジュール（100km/h以上）を設置 |

リスクの高いキャンペーンやハードモードのセーブデータに導入する前に、サンドボックスモードでさまざまなレイアウト構成をテストしておくことで、ネットワークインフラがあらゆる運行時代において無理なく拡張できるようになります。

## よくある質問

### 旅客ハブにおいて最も省スペースなTransport Fever 3の駅設計は何ですか？
最も省スペースな旅客ハブ構成は、2〜4線を有し、高架または地下の歩行者コンコースを備えた島式ホーム通過型駅です。両脇の2線で乗客待合エリアを共有することで、乗車速度を最大化しながら駅の横幅を最小限に抑えられ、建物の大規模な解体を伴わずに狭い都市回廊へ綺麗に収めることができます。

### 生産量が急増したときに貨物駅が溢れるのを防ぐにはどうすればよいですか？
生産量の急増に対応するには、モジュール式の貨物保管拡張ピースと補助積載プラットフォームを使用して駅を拡張します。すべての貨車が同時に積載・荷降ろしできるように、物理的なホームの長さを最長の貨物列車と一致させてください。さらに、鉄道ハブに専用のオフストリート複線トラック乗換ループを組み合わせることで、完成品が到着後すぐに目的地の商業・工業エリアへ配送されるようになります。

### 旅客駅の内部に専用の通過線を敷設すべきですか？
はい、急行列車が各駅停車の近郊駅を通過する主要回廊では、ホームのない中央通過線の設置が不可欠です。バイパス線を設けることで、高速都市間列車は乗客の乗降待ちや低速なプラットフォーム速度制限に邪魔されることなく、最高速度で駅構内を通過できます。

### ゲーム中盤から終盤における駅ホームの最適な長さはどれくらいですか？
ゲーム中盤から終盤において、大容量の連接急行編成を収容するための最適な旅客ホームの長さは240メートルから320メートルです。石炭から発電所、あるいは鉄鉱石から製鉄所へのルートなど、大容量のリソースチェーンを担当する貨物プラットフォームは、1回の高効率運行で十分な量を運べるよう、しばしば上限である320メートルまたは400メートルいっぱいに建設することが推奨されます。
